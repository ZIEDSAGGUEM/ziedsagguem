## 🚀 Featured Projects

### 🔹 [City_Service_Connect](https://github.com/ZIEDSAGGUEM)
`React` `TypeScript` `NestJS` `Prisma` `PostgreSQL` `Socket.io`

A local-services marketplace built end to end: provider search, service requests tracked from creation to completion, reviews and ratings.
- NestJS + Prisma backend on PostgreSQL with 11 data models, JWT authentication with email verification and three user roles
- Real-time messaging and notifications with Socket.io, provider and admin dashboards, and an AI assistant for service recommendations

### 🔹 [E-commerce Platform (PFE)](https://github.com/ZIEDSAGGUEM)
`React` `Redux Toolkit` `Node.js` `Express.js` `MongoDB` `Socket.io` `Cloudinary`

A MERN e-commerce platform with a product catalog (filters and stock), cart, favorites, and orders with cash on delivery or online card payment (Flouci).
- Express/MongoDB API with bcrypt authentication, admin/customer roles, Cloudinary uploads, discount coupons and Socket.io notifications
- Admin dashboard (products, orders, clients, MongoDB Charts) and a customer video-stories feature

### 🔹 [Leave_Management](https://github.com/ZIEDSAGGUEM)
`React` `TypeScript` `Node.js` `Express.js` `MongoDB` `Docker`

A full-stack leave management app with JWT and bcrypt security, Socket.io updates and PDF export, containerized with Docker Compose.
